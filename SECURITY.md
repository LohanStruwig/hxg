# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately through this repository's
[GitHub Security Advisories](https://github.com/LohanStruwig/hxg/security/advisories/new).
Do not open a public issue for credentials, personal data, dependency flaws, or
other information that could increase risk before a fix is available.

Include the affected URL or file, a concise reproduction, likely impact, and any
safe remediation idea you already have. Reports will be acknowledged through
the private advisory thread. Public disclosure will be coordinated after the
issue is contained and a fix is available.

The repository contains research artifacts and a static evidence explorer. It
does not operate a public API or collect visitor credentials.
