# HXG rights-aware research methodology

## Public description

HXG is **rights-aware, evidence-audited research with disclosed human governance**.

Version 0.3.0 is a deterministic rights-policy rebuild. No model-backed research run was executed.

## Research question

How can connected hospitality capabilities be organized into testable guest-outcome pathways, and what evidence would a property need before claiming operational or financial value?

## Rights gate

Every candidate must have a current `SourceRights` record approving automated acquisition, AI processing, and public republication. Unknown, denied, missing, conflicting, or expired permissions fail before an HTTP client is created. Link-only vendor records are structurally excluded from retrieval and evidence.

## Evidence states

- `fact`: a paraphrased statement from a reviewed open source;
- `supported-inference`: a bounded interpretation with explicit limitations;
- `modeled-scenario`: a transparent formula requiring local inputs and validation.

## Stages

1. Review source rights and domain.
2. Retrieve only approved material into the gitignored cache.
3. Extract paraphrased atomic claims with no public third-party excerpts.
4. Resolve entities and IDs deterministically.
5. Use GraphRAG only with approved cached content when a model-backed run is separately authorized.
6. Connect relationships and reject broken source chains.
7. Challenge analytical, accessibility, security, availability, and value assumptions.
8. Freeze counts, hashes, graph exports, site data, and publications in one manifest.

## Release gates

The release fails for a missing rights record, denied or unknown domain, expired review, false processing permission, vendor record in evidence, excerpt, broken claim/source relationship, unsupported causal wording, count divergence, or GraphML/JSON parity failure.
