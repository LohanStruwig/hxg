# HXG property-specific value model

HXG publishes variable-based scenarios so assumptions remain visible.

## Ancillary contribution

`eligible occupied room nights × measured engagement × incremental conversion × contribution margin`

## Energy value

`verified baseline × controllable share × measured attributable reduction`

## Operational support

`verified remote resolutions × measured avoided dispatch cost`

No universal rate, uplift, saving, conversion, or ROI is supplied. A property must define the baseline, counterfactual, attribution method, data quality checks, measurement period, and decision threshold before using a result.
