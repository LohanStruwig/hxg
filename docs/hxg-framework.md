# HXG six-pathway experience framework

HXG is an original analytical framework for asking how connected guest-facing capabilities might support six hospitality outcomes:

1. Cast from your device → feel at home.
2. Control room settings → feel in control.
3. Connect stay context → feel recognized.
4. Present content accessibly → feel included.
5. Protect sessions and data → feel secure.
6. Request services and help → feel supported.

The arrow means **can support**. It does not mean causes, proves, guarantees, improves, or delivers. Each pathway is a proposition to validate with the intended guests, property, interface, systems, and operating model.

The framework separates facts, supported inferences, and modeled scenarios. It keeps product availability, network readiness, data governance, accessibility, and security as conditions rather than assuming them away.
