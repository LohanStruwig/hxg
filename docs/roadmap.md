# Roadmap

## 0.1 — Seed release

- Versioned evidence schemas and run manifest.
- Deterministic graph exports and static explorer.
- Contradiction register, carousel, poster, and LinkedIn copy.

## 0.2 — Credentialed repeatability

- Execute the manager-led Agents SDK pipeline with an explicit budget.
- Refresh retrieved-content hashes and expand source-accessibility reporting.
- Run Microsoft GraphRAG indexing and compare proposed communities with deterministic records.
- Complete a second independent citation audit before replacing the seed release.

## 0.3 — Deeper analysis

- Add property-specific scenario templates without publishing customer data.
- Compare vendor architectures with a neutral capability ontology.
- Add downloadable accessible tables for communities and relationship paths.

No live AI query service or public write API is planned for version one.
