# HXG findings - release 0.3.0

## Working proposition

An in-room display can be treated as an orchestration layer connecting guest-facing capabilities, operational systems, and property-specific value questions.

This is an HXG analytical proposition, not a measured market finding.

## Six pathways

The framework maps six capabilities to six guest outcomes using the bounded verb `can-support`. Each pathway retains an original relationship ID and now resolves only to an original HXG claim with an explicit non-empirical limitation.

## Evidence and rights

The cleaned evidence set uses reviewed open-license, public-information, and original HXG records. Public claims contain no excerpts. Vendor pages are metadata-only links outside evidence and model context.

## Value model

Ancillary contribution, energy value, and operational support are variable-based scenarios. No universal rate or outcome is supplied.

## Principal contradictions

1. An analytical pathway is not preference evidence.
2. A formula is not ROI.
3. Accessible intent is not conformance.
4. Security controls do not guarantee perception or system security.

Generated counts and output hashes are in `data/public/run-manifest.json`.
